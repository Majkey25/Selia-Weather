- News app: No
- Government app: No
- Health features: No

## Data safety

- Data is encrypted in transit: Yes.
- Account creation: No.
- Approximate location and precise location: collected only after the user requests current location. The data supports app functionality and is not shared.
- Current-location lookup is ephemeral. Selected coordinates remain locally only as the selected place.
- Users can delete local app data in Android settings or by uninstalling the app.
- The app has no advertising, analytics, personalization, financial, health, contacts, messages, photos, files, audio, or device-identifier collection.
- A selected widget image stays on the device. The app retains read access to the Android document URI only while a configured widget uses it.
- The optional Buy Me a Coffee action opens an external HTTPS page. It grants no app feature, entitlement, or priority.

The location disclosure covers coordinates sent to Open-Meteo and Android Geocoder only after the user selects **Use my location**. ČHMÚ radar and satellite requests use normal HTTPS connections.

## Assets

`en-US` owns the icon, feature graphic, and phone screenshots. The `cs-CZ`, `de-DE`, `es-ES`, and `fr-FR` listings contain localised text only and omit image directories. Google Play inherits the default English assets for those listings, which avoids mismatched screenshots or feature graphics.
