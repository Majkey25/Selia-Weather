# Beta.24 verification

Version code 25 changes hourly presentation, not forecast weights or source data.

- 365 Android unit tests and 25 map tests passed. Debug/release lint, release APK/AAB and the release-optimized QA build passed.
- Tests cover matching an 11:00 display row to the source accumulation ending at 12:00, unchanged instantaneous temperatures, midnight/year boundaries, missing and duplicate endpoints, seconds-precision timestamps, unknown precipitation components and aligned graph bars.
