# Beta.25 verification

Version code 26 changes forecast layouts and detail interactions. Forecast calculations, source selection, and accumulation timestamps are unchanged.

## Reproduced defects

Four Compose UI tests ran on the Huawei Android 10 test phone before the fixes. All four failed on the reported behavior:

- The daily precipitation text was truncated in the narrow condition column.
- The graph's fixed 42 dp precipitation column clipped its amount at 200% font size.
- Tapping an expanded pressure metric collapsed the whole hour.
- The precipitation explanation was always visible instead of an independent disclosure.

The same four tests passed after the fixes. Tests inspect rendered text layouts and use actual touch input. Large-font cases use a local Compose density override, not a system-setting change.

Daily precipitation, wind, and feels-like values now use the full row width. Hour headers own the expand action; expanded statistics do not. Text grows with its contents, and highlighted rows retain rounded clipping and inner padding.

## Final physical checks

All five UI tests passed on the final build. The extra check covers the current time and Now labels. The disclosure test verifies both accessibility states and opening/closing without collapsing the hour.

The text assertion checks glyph-line bounds, height, and ellipsis. A diagnostic exposed a false overflow flag for the time label: its cached paragraph was 864 pixels wide, but its visible line ended at 136 inside a 137-pixel text box. The test checks rendered lines rather than cached paragraph width.

The R8-optimized, non-debuggable QA build updated the development app in place. Manual checks covered daily rows, the highlighted 17:00 hour with a 17:00–18:00 precipitation interval, scrolling through metrics, tapping pressure without collapsing the hour, and opening the precipitation explanation. A right swipe opened the next day with all 24 hours. A downward swipe from the top dismissed the sheet.

The hour highlight and explanation were visually inspected at 100% and 130% system font size. Text remained inside the padded background and wrapped without overlapping adjacent content. The original font scale, 1.0, was restored and verified. No AndroidRuntime errors were recorded for the QA process.

The temporary test APK and phone screenshot were removed. App data and the installed development app were preserved. The phone was released before the end of the reserved test window.

## Scope and limits

365 unit tests and 25 map tests passed. Debug and release lint completed with zero errors; existing warnings remain. Signed release APK/AAB and the R8-optimized QA build passed. The release APK manifest has no test activities or ad/payment components.

The UI test dependencies are limited to instrumentation and debug builds. CI compiles the instrumentation APK; the physical phone executes the UI tests. No emulator was created.

These checks do not establish better forecast accuracy. The existing forward precipitation interval remains unchanged: the 11:00 row uses the source accumulation ending at 12:00, while temperature and conditions stay at 11:00.
