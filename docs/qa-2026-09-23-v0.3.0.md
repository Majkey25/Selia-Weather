# Selia Weather 0.3.0 verification

Checked 22–23 September 2026. Android version code: 30. Release package remains `com.majkeylab.weatheraladin`.

## Changes verified

- Four-day preview expands to fourteen days, keeps day indices correct, and collapses again. Details and history follow the daily overview.
- Hourly advice uses short, data-driven sentences. Model counts remain available under the precipitation explanation; they are not converted into probabilities.
- Total hourly cloud cover is retained. Missing feels-like values stay unavailable. Hourly evapotranspiration follows its interval-ending source record.
- The future map uses actual DWD grids, not the previous sampled-point interpolation. Browser checks loaded Prague, New York and Tokyo forecasts. New York playback advanced to the next interval; Tokyo panning and source/legend controls worked at a 360×640 viewport.
- Native Android channels are independent. Rain/umbrella and official warnings default on; other new threshold categories default off. Existing morning-briefing preferences are preserved. OS-blocked categories are labelled in the app.
- ČHMÚ warnings use exact ČÚZK administrative-area membership. NWS point queries work for US coordinates without a country label. Provider failures never become an all-clear.

- JVM: **400 tests**, zero failures, errors or skips.
- JavaScript: **35 tests**, all passed.

- Debug APK, test APK, minified release APK and signed AAB built successfully. Release metadata reports 0.3.0 / 30. APK signature verification passed with the existing upload certificate.
- Huawei, Android 10 / WebView 151: **17 instrumentation tests passed** in the final run (`ForecastLayoutTest`, `WeatherWarningsDeviceTest`, `RadarWebViewTest`). Tests covered live source parsing, observed/future map loading, notification toggles and channel dispatch, blocked-channel messaging, expandable daily overview, hourly details and day swipes.
- Manual phone checks confirmed four visible day entries before “Show all 14 days”, then “View all weather details” and “Weather history”. The rain category opened its own native settings page; its temporary test toggle was restored.
- Forced job 7004 returned to waiting with no warning/error entries from the app's weather-job log tags. This checks execution, not delivery under every battery-management policy.

An initial native run exposed `Instant.parse` rejecting explicit offset timestamps on Android 10, although desktop JVM tests passed. The shared reader now uses `OffsetDateTime.parse(...).toInstant()` for warnings, station observations, calibration artifacts and static forecasts. A physical regression test covers Z, +00:00, +02:00 and -04:00. The subsequent live warning tests passed.

Review also corrected stale notification ordering, deduplication after changing locations, clock-correction recovery, DST-aware alert times, retained failed map tiles and expired model runs.

## Limits

- No new forecast-accuracy percentage or global superiority result was measured. Learned-weight validation gates remain intact. ALADIN's name alone is not evidence that an individual rain forecast is certain.
- Official in-app warning feeds cover Czechia and the US. UK access needs a suitable authenticated feed; other regions link to official sources and remain explicitly unavailable/unsupported.
- Global DWD images show six-hour totals and a coarser grid; ICON-EU shows hourly totals. Neither is a future radar observation. Provider outages remain possible.
- Android notifications are best effort, use the last selected place and can be delayed or disabled by Android. They do not replace local emergency systems. Android 13+ permission behavior was reviewed and linted, not tested on this Android 10 phone.
- Physical tests used the debug build. The minified release was built and signature-checked, not installed over the differently signed Play installation. Existing production data was preserved.
- Passing these checks is not evidence of Google Play approval or tester availability; publication status is verified separately.

Phone test package and owned device scratch files were removed. The development app and repository remain; the development app was stopped after testing.
